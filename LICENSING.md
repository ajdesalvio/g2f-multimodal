# Licenses and reuse

Different materials have different licenses; there is no blanket license for
all files and linked datasets.

| Material | License or terms |
| --- | --- |
| Original software in `functional-analysis/R/`, `scripts/`, and configuration, plus shared CI | [MIT](functional-analysis/LICENSE), except identified third-party material |
| Original functional-analysis documentation and figure artwork; shared README and citation metadata | [CC BY 4.0](functional-analysis/LICENSE-DOCUMENTATION.md) |
| `neural-process/` | Its existing [MIT license](neural-process/LICENSE), unchanged |
| Modified BGLR and the BGLR-derived patch | Upstream GPL-3 terms; not relicensed as MIT or CC BY |
| Data deposited on Dryad | CC0 under [Dryad's terms](https://datadryad.org/terms); the deposit is still being prepared |
| Michel et al. (2022) QTL/LD reference data | CC BY 4.0 as listed on the [source dataset record](https://doi.org/10.25386/genetics.19439684); downloaded separately |
| Data to Science collections, reference inputs, and other third-party data | Terms at the source dataset records and retained notices; no automatic relicensing here |

The MIT and CC BY notices do not assign a blanket license to numerical data
files. Cite dataset records for their terms and provenance; the planned Dryad
deposit will state the data license explicitly. The separate all-years G2F
prediction HapMap still requires source-accession and redistribution confirmation;
the Michel reference-data citation does not establish its provenance.

When reusing the authors' documentation or figures, credit the manuscript
authors and repository, link CC BY 4.0, and indicate changes. See
[CITATION.cff](CITATION.cff) for the author list. A published journal article's
license is governed by its publication record.

Third-party package dependencies retain their own licenses. The archived HPRC
library is not bundled in GitHub; a future redistribution must preserve its
packages' notices and satisfy applicable source-distribution requirements.
